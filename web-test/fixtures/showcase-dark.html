Welcome to ViewMD — the professional-grade Markdown preview engine built specifically for Android Studio and IntelliJ-based IDEs. ViewMD transforms static Markdown rendering into a responsive, offline-first developer workspace.

5. Callouts & Information Alerts

[!NOTE] ViewMD bundles all styling, fonts, and scripts directly inside the plugin archive. No remote HTTP or CDN requests are ever made.

[!TIP] Press Ctrl + Shift + X (or right-click in editor) to export a standalone HTML document ready for client presentations.

[!IMPORTANT] Compatible with Android Studio Ladybug, Meerkat, and IntelliJ IDEA 2026.2+ platforms.

[!WARNING] When defining custom CSS, use CSS variables (such as --viewmd-fg and --viewmd-bg) to maintain seamless dark and light mode synchronization.

6. Code Blocks with Instant Copy

Code blocks feature automatic syntax highlighting, clean margins, and one-click copy buttons:

package dev.mina.viewmd.export

object HtmlUtils {
    @JvmStatic
    fun escapeHtml(str: String): String {
        return str.replace("&", "&amp;")
            .replace("<", "&lt;")
            .replace(">", "&gt;")
            .replace("\"", "&quot;")
            .replace("'", "&#39;")
    }
}
